# Qryx 1.2.1

This is a patch release. It fixes the 2031 migrated count in the NCSC report, which read a literal 0 on every run, and it moves the OpenTelemetry dependency past GO-2026-6974. The binaries and the image, `ghcr.io/taipanbox/qryx`, are built on Go 1.27.4, as in 1.2.0. No name `compat/1.0.json` freezes is removed, renamed or added; the frozen surface is unchanged since 1.2.0.

## Fixed

- **The NCSC report measures the 2031 migrated count (#92).** `highestPriority2031.migratedCount` was the literal 0 in the JSON and on the HTML page, so a team that had replaced every exposed key read the same figure as a team that had done nothing. It is now measured against the `--baseline` snapshot the drift gate already loads: a highest-priority cryptographic asset in a baseline of the same target that is absent from the current asset graph counts as migrated. The migrated assets are listed in `migratedFindings`. Without a like-for-like baseline (none given, not found, another root, or another schema version) the count is JSON `null`, `migratedMeasured` is false, and the page says "migrated: not measured".
- **OpenTelemetry moves to v1.47.0 for GO-2026-6974 (#92).** govulncheck found the `AttributeValueLengthLimit` bypass reachable through `go.opentelemetry.io/otel/trace` v1.44.0, an indirect dependency of the AWS and Google SDKs. `otel` and `otel/metric` move with it, and `go-logr/logr` moves to v1.4.4.

## Upgrade

Pull `ghcr.io/taipanbox/qryx:v1.2.1` in place of `v1.2.0`, or download the binary for your platform from this release. No setting, stored state or wire format changes.

A consumer that read `highestPriority2031.migratedCount` as a number now receives `null` unless it runs the NCSC report with a like-for-like `--baseline`. The HTML page reads "migrated: not measured" in the same case. Check any dashboard or gate that reads this field before upgrading. To roll back, run 1.2.0 again.

## Changed since 1.2.0

- #92, `fix(ncsc): measure the 2031 migrated count from the baseline, or say it was not measured`, with the OpenTelemetry bump above. Invariant 23 in `CLAUDE.md`, `features/ncsc-migrated.feature`, and four gates-have-teeth cases, each run red first.
- #89, `deps: agent-stack-go v2.0.3 (Go 1.27.4 rebuild)`, the rebuild of the shared wire types on Go 1.27.4; no Go code changes.
